Otwórz panel licencji

Działa tylko wtedy, gdy panel licencji jest uruchomiony na tym samym komputerze. Logowanie zdalne nie jest dostępne.

Panel nie odpowiada?

Mac: Uruchom plik scripts/otworz-panel-licencji.command z lokalnego klonu repozytorium (dwuklik w Finderze lub open w terminalu). Szczegóły: instrukcja w repozytoriumprywatne repo.

Wiersz poleceń: w katalogu projektu wpisz
npm run licenses:admin
